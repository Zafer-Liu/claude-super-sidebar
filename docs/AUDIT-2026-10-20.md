## 新增适配的检查

- 按项目完整路径过滤会话；HTTP 客户端不能提交任意文件路径。
- 回环绑定、Host/Origin/Fetch Metadata 检查、GET/HEAD 限制和静态资源白名单；拒绝跨来源访问和 DNS 重绑定 Host。
- 严格 CSP 与 DOM 文本渲染；不执行日志内容，不回传原始工具参数/输出、隐藏推理、登录凭据或完整对话。
- 增量读取、中文 UTF-8 跨块、半行追加、文件截断、符号链接、坏行恢复及未完成首行重试均有测试。
- 并行调用以 `call_id` 独立更新，不因缺失结果猜测成功；计划只在工具成功返回后更新；Token 使用累计值而非重复相加。
- 新增代码零第三方运行时依赖，未引入 API Key 或额外模型请求。

## 保留的限制

1. Codex rollout 是本地实现格式，未来版本可能变化；不是正式的原生 UI 插件 API。独立面板无法保证观测未落盘或云端会话。
2. 文件最后状态不等于进程存活，异常退出可能保留“运行中”；README 说明该边界，按用户要求界面已移除相关机制说明文字。
3. 不能完整还原通用 `exec` 的内部多工具结构；每项目最多 100 个最近活动会话、每轮 30 步。跨项目路径子代理不纳入当前项目。
4. Claude 原生组件及早期引擎 API 仍需要兼容宿主。本次新增回归运行真实解析源码与模拟宿主钩子，未将其等同于真实 Claude 引擎或 Desktop 绘制验证。
5. 原生界面的颜色主要为固定浅色；本次保持既有界面范围。原项目的整体许可证仍未声明，第三方声明保留。
